# 製造業向け無料ツール候補 調査メモ

更新日: 2026-09-01

## 方針

検索入口は Microsoft 製品名ではなく、製造業の現場課題・業務ドメインを起点とする。解決手段として Microsoft 365 / Power Platform を提示する。

## 優先候補

### 1. BOM / 図面・設計変更の「Excel限界判定 + 改善ナビ」

対象課題:
- 最新版が分からない
- 変更が購買・製造へ届かない
- Excelコピーが増殖している
- E-BOM / M-BOM の差分・反映漏れ
- 図面差替え漏れ

無料ツール案:
- 製品数、BOM階層、改訂件数/月、関係部署数、ファイル数、承認有無を入力
- リスクを「版管理」「変更伝達」「転記」「トレーサビリティ」「属人化」に分解
- Excel継続 / SharePoint・Lists / Power Automate / Power Apps / 専用PLM の適用境界を表示
- Microsoft 365でスモールスタートできる範囲と、PLMが必要になる範囲を分けて提示

案件化ポイント:
- SharePoint文書管理
- Listsによる品目・変更台帳
- Power AutomateによるECR/ECO/ECN承認・通知
- Power Appsによる現場参照・変更受付

### 2. 製造業 在庫・仕掛品 Excel限界判定

対象課題:
- 棚卸差異
- ロット/仕掛品が追えない
- 入出庫転記
- 複数人同時更新
- 部品・仕掛・完成品が別管理

無料ツール案:
- 品目数、ロット有無、拠点数、棚卸頻度、入出庫件数、差異発生頻度を入力
- Excel継続 / Lists / Power Apps / 専用在庫システムの適用境界を表示

### 3. 工場点検・日報 デジタル化構成ジェネレーター

対象課題:
- 紙点検
- Excel転記
- 写真添付
- 異常時の通知漏れ
- 月次集計

無料ツール案:
- 点検種類、件数、写真有無、異常通知、承認、集計条件を選択
- Power Apps + Lists + Power Automate の構成図・概算難易度を即時生成

## 現時点の優先順位

1. BOM / 図面・設計変更
2. 在庫・仕掛品
3. 点検・日報
4. 生産進捗
5. 品質不具合 / 是正処置

理由:
- BOM / 図面・設計変更は、最新版・改訂・変更伝達という検索課題が明確で、製造業固有性が高い。
- 在庫は検索需要が広いが、専用SaaS競合も強い。Microsoft案件への接続は可能だが、在庫システムとして売るより「Excel限界判定」が安全。
- 点検はPower Appsとの親和性が非常に高い一方、無料Excelテンプレート競合が多いため、テンプレ配布ではなく構成ジェネレーターにする。

## ガードレール

- 入力データをサーバーへ保存しない構成を初期版の原則とする。
- 「Microsoft製品で何でも解決できる」とは表現しない。
- PLM / ERP / MES / WMS が適切な領域は明示して案件誘導のために無理にPower Platformへ寄せない。
- 数値根拠がない場合は「推定」「目安」と明示する。
